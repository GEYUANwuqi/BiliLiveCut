# BiliLiveCut 控制台

React 19 + TypeScript + Vite，Tailwind CSS 4 + shadcn/ui。

```bash
npm ci
npm run dev
```

开发地址 `http://127.0.0.1:5173`，API 默认 `http://127.0.0.1:8000`（可通过 `BLC_API_PROXY` 修改）。生产构建 `npm run build`，使用独立静态服务和同源 API 反向代理。完整开发、部署、API 类型及测试说明见 [Web 页面开发](../docs/development/frontend.md)。
